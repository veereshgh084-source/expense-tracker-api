Expense Tracker API 💰

A simple Expense Tracker REST API built using Python and FastAPI.

This project helps users manage their daily expenses through API endpoints and JSON data.

🚀 Features

* Create a new expense
* View all expenses
* Store expense title, amount, and category
* Manage expenses using REST API endpoints
* JSON-based request and response handling

🛠️ Technologies Used

* Python
* FastAPI
* Pydantic
* REST API
* JSON

⚙️ Installation

1. Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project folder:

cd expense-tracker-api

3. Install dependencies:

pip install fastapi uvicorn

4. Run the application:

python -m uvicorn main:app --reload

🔗 API Documentation

After running the application, open:

http://127.0.0.1:8000/docs

Explore and test the API using Swagger UI.
